MOTO TUDO - GESTÃO DE ESTOQUE

Abra index.html em um navegador moderno.

Recursos funcionais deste protótipo:
- Dashboard calculado com base no estoque.
- Cadastro, edição e exclusão de produtos.
- Busca e filtros por categoria/status.
- Entrada, saída/venda e inventário.
- Histórico de movimentações.
- Financeiro simulado com custo, venda e margem.
- Cadastro de fornecedores.
- Configurações e alertas.
- Persistência local no navegador via localStorage.
- Layout responsivo para desktop e celular.

Observação: é um protótipo front-end. Os dados ficam salvos apenas no navegador usado.
